회사 네트워크 등에서 업데이트 확인이 "GitHub 응답 403"으로 실패하던 문제를 고친 버전이에요.

## 업데이트

- 0.2.0에서 업데이트 확인이 403으로 실패하면, 한 시간쯤 뒤 다시 확인하거나 아래 **Gitty-0.2.1.dmg**를 내려받아 덮어써 주세요. 이번 버전부터는 막히지 않아요.
- 0.1.1 이하에서는 dmg를 내려받아 응용 프로그램 폴더에 덮어써 주세요.

## 고친 점

- **업데이트 확인 403**: GitHub은 로그인 없이 확인하면 같은 네트워크 주소에서 한 시간에 60번까지만 받아 줘요. 여러 사람이 한 주소를 쓰는 회사 네트워크에서는 이 한도에 걸렸어요. 이제 막히면 GitHub CLI(gh) 로그인으로 다시 확인하고(한 시간에 5000번), 그것도 안 되면 릴리스 페이지에서 최신 버전을 알아내요. 어느 길로 받든 dmg 서명은 똑같이 확인해요.

## 알려진 제한

- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.
