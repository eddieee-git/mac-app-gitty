Google Drive를 **미러링**으로 쓸 때 내 드라이브가 빈 폴더로 보이던 문제를 고친 버전이에요.

## 업데이트

- 0.1.2 이상을 쓰고 있으면 Gitty가 알려 줘요. **내려받기**를 누르거나, 자동 설치를 켜 두었으면 종료할 때 설치돼요.
- 0.1.1 이하에서는 아래 **Gitty-0.1.5.dmg**를 내려받아 응용 프로그램 폴더에 덮어써 주세요.

## 고친 점

- **미러링이면 실제 내 드라이브를**: 미러링에서는 실제 파일이 홈의 `My Drive`에 있고 `~/Library/CloudStorage` 쪽은 거의 비어 있어요. 0.1.4는 빈 쪽을 내 드라이브로 보여 줬는데, 이제 실제 폴더를 "내 드라이브 (이메일)"로 보여 줘요.
- **즐겨찾기 정리**: 0.1.4가 즐겨찾기에 넣은 빈 내 드라이브를 빼고 실제 폴더를 넣어요.
- **못 읽는 폴더 안내**: 폴더를 읽지 못하면 "빈 폴더입니다" 대신 이유를 보여 주고, macOS가 막은 경우 시스템 설정에서 허용하는 방법을 알려 줘요.

## 알려진 제한

- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.
