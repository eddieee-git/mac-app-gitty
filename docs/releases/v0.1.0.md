Gitty의 첫 테스트 버전이에요. Git 저장소를 파일 관리자처럼 다룰 수 있어요.

## 설치

1. 아래 **Gitty-0.1.0.dmg**를 내려받아 열고, Gitty를 응용 프로그램 폴더로 끌어다 놓으세요.
2. 처음 열 때 경고가 나오면 **완료**를 누른 뒤:
   - macOS 15 이상: 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**
   - macOS 14: 응용 프로그램 폴더에서 Gitty를 **오른쪽 클릭 → 열기**
3. private 저장소를 쓰려면 터미널에서 `brew install gh`와 `gh auth login`을 한 번 해 주세요.

## 기능

- 왼쪽 내 폴더 / 오른쪽 Git 저장소 두 패널
- 패널 사이 끌어다 놓기로 업로드·내려받기, 오른쪽 클릭으로 이동
- 업로드, 삭제, 이름 변경, 새 폴더를 하면 바로 커밋·push
- Finder에서 끌어다 놓기, Finder로 끌어내기
- GitHub CLI 로그인으로 private 저장소 인증

## 알려진 제한

- macOS 14 이상 (Apple 실리콘, Intel 모두)
- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.
- 원격에서 같은 파일이 바뀌어 충돌하면 자동으로 합치지 않고 알려 주기만 해요.
- 앱 아이콘은 아직 없어요.
