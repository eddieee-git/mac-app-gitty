끌어다 놓기 업로드를 고치고, 윈도우 탐색기처럼 쓸 수 있게 크게 바꾼 버전이에요.

## 설치와 업데이트

1. 아래 **Gitty-0.1.1.dmg**를 내려받아 열고, Gitty를 응용 프로그램 폴더로 끌어다 놓으세요(이전 버전이 있으면 덮어쓰기).
2. 처음 열 때 경고가 나오면 **완료**를 누른 뒤:
   - macOS 15 이상: 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**
   - macOS 14: 응용 프로그램 폴더에서 Gitty를 **오른쪽 클릭 → 열기**
3. 100MB가 넘는 파일을 올리려면 터미널에서 `brew install git-lfs`를 한 번 실행해 주세요.

## 고친 점

- **끌어다 놓기 업로드가 안 되던 문제**: 파일 목록 위에 놓은 파일이 무시되던 문제를 고쳤어요. 이제 목록 어디에 놓아도 업로드·내려받기가 돼요.
- **최근 저장소가 잘 안 열리던 문제**: 첫 화면 목록에서 더블클릭해도 반응이 없던 문제를 고쳤어요. 줄 어디든 더블클릭, Return 키, 또는 **열기** 버튼으로 열리고, 여는 동안 표시가 나와요.

## 새 기능

- **탐색기 같은 화면**: 양쪽 패널 모두 왼쪽에 폴더 트리, 오른쪽에 파일 목록이 보여요.
- **Finder 같은 즐겨찾기와 위치**: Finder 기본 즐겨찾기로 시작하고, 폴더를 추가·제거·순서 변경할 수 있어요. Google Drive, iCloud Drive, Dropbox, OneDrive, 외장 드라이브는 "위치"에 자동으로 나와요.
- **Git 쪽 즐겨찾기**: 저장소 안의 자주 쓰는 폴더도 즐겨찾기에 추가할 수 있어요. 저장소마다 따로 기억해요.
- **폴더 위에 놓기**: 목록이나 트리의 폴더 위에 놓으면 그 폴더 안으로 들어가요. 같은 패널 안에서 놓으면 이동이에요(Git 쪽은 `git mv`로 커밋).
- **진행률**: 큰 파일 복사, push, LFS 업로드가 몇 % 진행됐는지 아래 상태 표시줄에 보여요.
- **100MB 넘는 파일은 Git LFS로**: 자동으로 LFS로 올리고, LFS를 쓰는 저장소를 열면 실제 파일을 받아요. 파일 하나 2GB까지예요.
- **자동 동기화**: 기본 5분마다 원격을 확인해서 다른 곳에서 올린 변경을 받아 와요. 설정(⌘,)에서 간격을 바꾸거나 끌 수 있어요.
- **검색**: 각 패널 위쪽 검색 상자로 하위 폴더까지 이름으로 찾아요.
- **진행 로그와 작업 기록**: 창 아래에 진행 로그가 실시간으로 보이고, 모든 기록은 `~/Library/Logs/Gitty/gitty.log`에 남아요(⌥⌘L로 전체 기록 보기).
- **앱 아이콘**이 생겼어요.

## 알려진 제한

- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.
- 데스크탑·문서·다운로드·Google Drive를 처음 열 때 macOS가 접근 허용을 물어요.
- 원격에서 같은 파일이 바뀌어 충돌하면 자동으로 합치지 않고 알려 주기만 해요.
