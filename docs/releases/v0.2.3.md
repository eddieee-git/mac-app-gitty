더블클릭으로 바로 주고받고, 실수는 되돌리고, 저장소를 더 편하게 관리하도록 다듬은 버전이에요.

## 설치와 업데이트

- **0.2.2를 쓰고 있다면**: Gitty가 새 버전을 찾으면 알아서 설치해요(자동 설치는 이번부터 기본 켬). 바로 받으려면 메뉴 **Gitty → 새 버전 0.2.3 설치…**나 설정 → 업데이트 → **지금 확인**을 누르세요.
- **0.2.1 이하이거나 처음 설치한다면**: 아래 **Gitty-0.2.3.dmg**를 내려받아 Gitty를 응용 프로그램 폴더로 끌어다 놓으세요. 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요(macOS 14는 오른쪽 클릭 → 열기).

## 새 기능

- **더블클릭으로 주고받기**: 내 폴더의 파일을 더블클릭하면 Git으로 올리고, Git의 파일을 더블클릭하면 내 폴더로 받아요. 처음 한 번 물어보고, 설정 → 화면에서 "열기"로 바꿀 수 있어요. 파일 열기는 Return이에요.
- **Git 휴지통**: Git 패널 위쪽의 휴지통 단추로 지운 파일을 골라 원래 자리에 되살려요.
- **새 저장소 만들기**: 첫 화면에서 이름만 넣으면 비공개 저장소를 만들고 바로 열어요.
- **브랜치 고르기**: Git 패널 경로 줄 왼쪽에서 브랜치를 바꾸거나 새로 만들어요.
- **저장소 용량**: 상태 표시줄에 저장소와 LFS 크기가 보이고, GitHub 권장 크기(1GB)의 80%를 넘으면 알려 줘요.
- **커밋 메시지 직접 쓰기**: 설정 → 커밋에서 켜면 올리기 전에 메시지를 쓸 수 있어요(기본 끔).
- **지난 저장소 다시 열기**: 다시 켜면 탭마다 열어 둔 저장소와 폴더가 그대로 열려요.
- **작업 끝 알림**: 오래 걸린 작업이 끝나면 다른 앱을 쓰고 있어도 알려 줘요.

## 바뀐 점

- **작업 줄 세우기**: 다른 작업 중에 파일을 놓아도 거절하지 않고 차례대로 해요. 상태 표시줄에 대기 수가 보여요.
- **되돌리기 확대**: 내 폴더 쪽의 휴지통 보내기, 옮기기, 이름 바꾸기도 ⌥⌘Z로 되돌려요.
- **알아듣기 쉬운 오류**: 인터넷 끊김, GitHub 로그인 풀림, 권한 없음, 100MB 넘는 파일 같은 오류를 할 일과 함께 알려 줘요. 오프라인이면 창 없이 상태 표시줄에만 보이고, 연결되면 올려요.
- **업데이트 자동 설치 기본 켬**: 직접 확인해도 묻지 않고 바로 설치해요.
- **더 빨라짐**: 폴더만 옮겨 다닐 때 저장소 전체를 다시 검사하지 않고, 파일을 많이 지울 때도 한 번에 처리해요. 폴더 맞추기는 아직 내려받지 않은 클라우드 파일을 읽지 않아요.
- 저장소를 열 때 GitHub 로그인이 풀렸으면 미리 알려 줘요.

## 고친 점

- 업로드를 커밋 직전에 취소하면 복사한 파일이 저장소 폴더에 남던 문제를 고쳤어요.
- "이 버전 열기"로 꺼낸 임시 파일이 계속 쌓이던 것을 정리해요.

## 보안

- 올리기 전에 파일 이름뿐 아니라 **내용**에서도 비밀 키와 토큰(AWS, GitHub, Slack, Google, Stripe 등)을 찾아 물어봐요.
- 이미 올린 비밀 정보는 지워도 기록에 남으니 키를 폐기하라고 안내해요.
- 저장소가 공개로 바뀌면 알아채고, 다음 업로드 때 다시 확인해요.

## 알려진 제한

- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.

## English

Gitty 0.2.3 lets you copy with a double-click, undo more mistakes, and manage repositories more easily.

**Installing and updating**
- On 0.2.2, Gitty installs the new version on its own once it finds it (automatic installs are now on by default). To get it right away, use **Gitty → Install Version 0.2.3…** or Settings → Updates → **Check Now**.
- On 0.2.1 or earlier, or for a new install, download **Gitty-0.2.3.dmg** below and drag Gitty into Applications. If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security (on macOS 14, right-click → Open).

**New**
- **Double-click to copy**: double-click a file in your folder to upload it to Git, or a file in Git to download it. Gitty asks once the first time; switch to "Open" in Settings → Display. Return opens a file.
- **Git Trash**: restore deleted files to where they were from the trash button above the Git pane.
- **New repository**: create a private repository from the start screen and open it right away.
- **Branches**: switch or create branches from the left of the Git pane's path bar.
- **Repository size**: the status bar shows repository and LFS size and warns at 80% of GitHub's recommended 1 GB.
- **Write commit messages**: turn on in Settings → Commit (off by default).
- **Reopen where you left off**: each tab reopens its repository and folder.
- **Completion notifications** for long tasks while you're in another app.

**Changed**
- Tasks started while another is running now wait their turn instead of being refused; the status bar shows how many are waiting.
- Undo (⌥⌘Z) also covers moving to Trash, moving, and renaming in your folder.
- Plain-language errors for no connection, signed-out GitHub, missing permission, and files over 100 MB. When offline, the status bar says so and uploads resume when you're back.
- Automatic update installs are on by default, and manual checks install without asking.
- Faster: no full repository scan when you only move between folders, faster bulk deletes, and folder sync no longer reads cloud files that aren't downloaded.
- Warns when your GitHub sign-in has expired as soon as a repository opens.

**Fixed**
- Cancelling an upload right before the commit no longer leaves copied files in the repository folder.
- Temporary files from "Open this version" are cleaned up.

**Security**
- Checks file contents, not just names, for private keys and tokens (AWS, GitHub, Slack, Google, Stripe, and more) before uploading.
- Explains that secrets already uploaded stay in the history and should be revoked.
- Notices when a repository becomes public and asks again before the next upload.

**Known limitations**
- Not signed by Apple, so macOS warns on first launch from the dmg.
