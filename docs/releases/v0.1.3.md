여러 Mac에서 같은 저장소를 쓸 때 생기는 충돌을 직접 고를 수 있게 하고, 스페이스바 미리 보기를 넣은 버전이에요.

## 업데이트

- 0.1.2를 쓰고 있으면 Gitty가 알려 줘요. **내려받기**를 누르거나, 설정에서 자동 설치를 켜 두었으면 종료할 때 설치돼요.
- 0.1.1 이하에서는 아래 **Gitty-0.1.3.dmg**를 내려받아 응용 프로그램 폴더에 덮어써 주세요.

## 새 기능

- **충돌 정리**: 다른 Mac에서 같은 파일을 바꿔 충돌하면, 파일마다 **내 것 / 원격 것 / 둘 다** 중에 고를 수 있어요. 둘 다 남기면 원격 것은 `이름 (원격).확장자`로 옆에 저장돼요. **나중에**를 누르면 내 쪽 그대로 두고 다음 동기화 때 다시 물어요. 앱을 껐다 켜도 이어서 물어요.
- **미리 보기**: 파일을 고르고 스페이스바를 누르면 Finder처럼 바로 보여요. 오른쪽 클릭 → **미리 보기**도 돼요.

## 고친 점

- 상태 표시줄 문구에서 이름을 따옴표로 감싸, "새 폴더 폴더를 만들었습니다"처럼 말이 겹치던 것을 정리했어요.

## 알려진 제한
