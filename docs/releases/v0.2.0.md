보안, 속도, 편의성을 크게 다듬은 버전이에요. 탭으로 저장소를 여러 개 열고, 폴더를 통째로 맞추고, 영어 화면도 쓸 수 있어요.

## 업데이트

- 0.1.2 이상을 쓰고 있으면 Gitty가 알려 줘요. **내려받기**를 누르거나, 자동 설치를 켜 두었으면 종료할 때 설치돼요.
- 0.1.1 이하에서는 아래 **Gitty-0.2.0.dmg**를 내려받아 응용 프로그램 폴더에 덮어써 주세요.

## 새 기능

- **가운데 복사 단추**: 두 패널 사이의 ▶는 내 폴더 → Git, ◀는 Git → 내 폴더로 복사해요(⌥⌘→, ⌥⌘←).
- **폴더 맞추기**: 가운데 ⇄ 단추로 지금 보는 두 폴더를 비교하고, 한쪽을 다른 쪽과 같게 맞춰요. 바뀌는 내용을 먼저 보여 줘요.
- **탭**: ⌘T로 새 탭, ⌘N으로 새 창. 탭마다 다른 저장소를 열 수 있어요.
- **아이콘 보기**: 패널마다 목록 보기와 아이콘 보기를 바꿀 수 있어요. 사진은 미리보기로 보여요.
- **배치와 크기 기억**: 패널마다 폴더 트리를 좌우 또는 위아래로 놓을 수 있고, 칸 크기와 진행 로그 높이를 기억해요.
- **파일 상태 표시**: 저장소 폴더에서 직접 고친 파일, Git에 없는 파일, 아직 안 올라간 파일, 아직 안 받은 큰 파일에 표시가 붙어요. 직접 고친 파일은 **올리기**로 바로 올려요.
- **GitHub 링크**: 오른쪽 클릭 → GitHub에서 보기 / 링크 복사.
- **키보드**: Tab으로 패널 오가기, Return 열기, ⌘↑ 상위 폴더, ⌘⌫ 삭제, 글자를 치면 그 이름으로 이동.
- **작업 취소**: 오래 걸리는 업로드·내려받기·동기화를 상태 표시줄의 **취소**로 멈춰요. 커밋 전이면 원래대로 되돌려요.
- **영어 화면**: 설정 → 화면 → 언어에서 고를 수 있어요(기본은 시스템 언어).

## 보안

- `.env`, SSH 키, 인증서처럼 비밀 정보가 들어 있을 법한 파일을 올리기 전에 물어봐요. Git에 올라간 파일은 지워도 기록에 남기 때문이에요.
- 공개 저장소에 올릴 때는 처음 한 번 확인해요.
- 설정에서 작업 기록을 파일로 남기지 않게 할 수 있어요.

## 더 빨라진 점

- 보고 있는 폴더가 바뀌면 바로 반영해요(Finder에서 바꾼 것도).
- 저장소를 처음 받을 때 지난 버전의 파일 내용은 필요할 때 받아서 빨리 열려요.
- 설정에서 **큰 파일은 열거나 복사할 때만 받기**를 켤 수 있어요.
- 큰 폴더에서 목록이 더 빨라졌어요.
