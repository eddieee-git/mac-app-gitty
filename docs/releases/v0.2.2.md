업데이트를 다섯 앱 공통 방식으로 바꾸고, 설정에 정보 칸을 더한 버전이에요. 폴더 비교와 복사 기능은 그대로예요.

## 설치와 업데이트

- **0.2.0이나 0.2.1을 쓰고 있다면**: Gitty가 새 버전을 알려 줘요. 안내대로 설치하면 돼요. 알림이 안 보이면 아래 **Gitty-0.2.2.dmg**를 내려받아 응용 프로그램 폴더에 덮어써 주세요.
- **0.1.x이거나 처음 설치한다면**: 아래 **Gitty-0.2.2.dmg**를 내려받아 Gitty를 응용 프로그램 폴더로 끌어다 놓으세요. 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요(macOS 14는 오른쪽 클릭 → 열기).
- 다음 버전부터는 메뉴의 **새 버전 X 설치…**나 설정의 **지금 확인**으로 받아요.

## 바뀐 점

- **업데이트 설정**: 설정의 업데이트 칸에서 자동 확인(기본 켬)과 자동 설치(기본 끔)를 따로 정해요. 자동 설치를 켜면 Gitty를 쓰지 않고, 올리는 중인 것도 남은 push도 없을 때만 바꿔 넣어요.
- **업데이트 확인 강화**: 받은 파일의 서명, SHA-256, 번들 ID, 버전, 코드 서명을 모두 확인한 뒤에만 설치해요.
- **요청 한도에 덜 막힘**: GitHub 요청 한도(403·429)에 걸리면 릴리스 페이지에서 최신 버전을 알아내요. gh 로그인은 더 쓰지 않아요.
- **정보 칸**: 설정에 버전, GitHub, 변경 기록, 문제 알리기, 같은 사람이 만든 다른 앱 링크가 생겼어요.
- 업데이트 알림 창, 이 버전 건너뛰기, 종료할 때 설치는 없앴어요. 창 위 알림 띠와 메뉴 항목으로 알려 줘요.
- 알림과 안내 문구를 부드러운 말투로 맞췄어요.

## 알려진 제한

- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.

## English

Gitty 0.2.2 moves updates to the updater shared by all five apps and adds an About section to Settings. Folder comparison and copying are unchanged.

**Installing and updating**
- On 0.2.0 or 0.2.1, Gitty tells you about the new version; follow its prompt. If you don't see it, download **Gitty-0.2.2.dmg** below and replace Gitty in Applications.
- On 0.1.x or a new install, download **Gitty-0.2.2.dmg** and drag Gitty into Applications. If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security (on macOS 14, right-click → Open).
- From the next version on, use **Install Version X…** in the menu or **Check Now** in Settings.

**Changed**
- **Update settings**: separate switches for automatic checks (on by default) and automatic installs (off by default). Automatic installs happen only while Gitty is idle, with no upload in progress and nothing left to push.
- **Stronger update checks**: installs only after the signature, SHA-256, bundle ID, version, and code signature are verified.
- **Fewer rate-limit failures**: when GitHub's rate limit (403/429) is hit, Gitty reads the latest version from the releases page. It no longer uses your gh login.
- **About section**: version and links to GitHub, the changelog, problem reports, and other apps by the same developer.
- The update dialog, Skip This Version, and install-on-quit are gone; the banner at the top of the window and the menu item tell you instead.
- Friendlier tone in Korean messages.

**Known limitations**
- Not signed by Apple, so macOS warns on first launch from the dmg.
