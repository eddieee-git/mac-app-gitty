Google Drive의 **내 드라이브**가 보이지 않던 문제를 고친 버전이에요.

## 업데이트

- 0.1.2 이상을 쓰고 있으면 Gitty가 알려 줘요. **내려받기**를 누르거나, 자동 설치를 켜 두었으면 종료할 때 설치돼요.
- 0.1.1 이하에서는 아래 **Gitty-0.1.4.dmg**를 내려받아 응용 프로그램 폴더에 덮어써 주세요.

## 고친 점

- **내 드라이브 찾기**: Google Drive를 "미러링"으로 쓰면 내 드라이브가 다른 폴더(기본은 홈의 `My Drive`)에 있어서, 공유 드라이브만 보이던 문제를 고쳤어요. 스트리밍·미러링 모두 찾아요. 다른 곳에 두셨으면 Spotlight로 찾아요.
- **위치 맨 위에 내 드라이브**: 계정이 여러 개면 "내 드라이브 (이메일)"로 구분해요.
- **즐겨찾기에 자동 추가**: 찾은 내 드라이브를 즐겨찾기에 한 번 넣어 줘요. 빼시면 다시 넣지 않아요.
- 폴더를 가리키는 바로가기(심볼릭 링크)도 폴더로 보여요.
- 그래도 안 보이면 작업 기록(⌥⌘L)의 "클라우드 폴더 … 내 드라이브 …" 줄을 알려 주세요.

## 알려진 제한

- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.
