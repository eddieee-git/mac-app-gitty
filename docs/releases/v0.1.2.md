자동 업데이트, 되돌리기, 변경 기록이 생기고 보안과 속도를 다듬은 버전이에요.

## 설치와 업데이트

1. 아래 **Gitty-0.1.2.dmg**를 내려받아 열고, Gitty를 응용 프로그램 폴더로 끌어다 놓으세요(이전 버전이 있으면 덮어쓰기).
2. 처음 열 때 경고가 나오면 **완료**를 누른 뒤:
   - macOS 15 이상: 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**
   - macOS 14: 응용 프로그램 폴더에서 Gitty를 **오른쪽 클릭 → 열기**
3. 이번 버전부터는 새 버전이 나오면 Gitty가 알려 줘요. 0.1.1에서 올 때만 이렇게 직접 설치해 주세요.

## 새 기능

- **자동 업데이트**: 새 버전이 나오면 알려 주고 내려받아 줘요. 설정(⌘,)에서 **업데이트를 자동으로 설치**를 켜면 미리 받아 두었다가 종료할 때 설치해요. 메뉴 **Gitty → 업데이트 확인…**으로 직접 확인할 수도 있어요.
- **Git 작업 되돌리기**: 마지막 업로드·삭제·이름 변경·이동을 ⌥⌘Z나 상태 표시줄의 **되돌리기**로 되돌려요. 기록은 지우지 않고 되돌리는 커밋을 새로 만들어요.
- **변경 기록**: Git 쪽 파일을 오른쪽 클릭 → **변경 기록…**에서 지난 버전을 열어 보거나 그 버전으로 되돌려요. 이름이 바뀌기 전 기록도 따라가요.
- **목록 정렬**: 이름·크기·수정한 날짜 열 제목을 누르면 정렬돼요. 폴더는 늘 위에 있어요.
- **첫 실행 안내**: git, GitHub CLI, GitHub 로그인, Git LFS 중 빠진 게 있으면 첫 화면에서 설치 명령을 알려 줘요.

## 고친 점

- **업데이트 파일 서명 확인**: 받은 업데이트가 진짜인지 Ed25519 서명으로 확인하고, 맞지 않으면 설치하지 않아요.
- **바뀐 파일만 커밋**: 클론 폴더에 따로 넣은 파일이나 Finder의 `.DS_Store`가 함께 올라가던 문제를 고쳤어요.
- **화면 멈춤**: Google Drive·네트워크 폴더를 열 때 앱이 멈추던 문제를 고쳤어요. 목록과 폴더 트리를 뒤에서 읽어요.
- **검색**: 검색어를 바꾸면 이전 검색이 바로 멈추고, 큰 폴더에서는 훑는 범위에 한도를 둬요.
- **빨라진 push**: 연달아 한 작업은 모아서 한 번에 올려요. 올리기 전에 종료해도 마저 올린 뒤 꺼져요.
- **자동 동기화**: 원격에 바뀐 게 있을 때만 LFS 파일을 받아요.
- **작업 기록**: 원격 주소에 들어 있는 토큰은 가려서 남겨요.

## 알려진 제한

- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.
- 원격에서 같은 파일이 바뀌어 충돌하면 자동으로 합치지 않고 알려 주기만 해요.
